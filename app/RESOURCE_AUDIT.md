## Question-bank policy and generated evidence

The current bank is generated by `app/scripts/extract_resources.py`, which reads DOCX paragraph XML, identifies question blocks and answer-key blocks, and writes `app/data/questions.json`. The application consumes that JSON directly through `src/data.ts`; it no longer uses the former hand-authored AI-default array.

Current result: **45 questions used, 45 provided-resource questions, 0 AI-generated gap-fill, 0 verified actual PYQs**. No item is labeled `actual_pyq` solely because a filename contains “PYQ”. The exact source filename and question identifier are stored on every record. See [QUESTION_BANK_REPORT.md](QUESTION_BANK_REPORT.md) for the topic breakdown and limitations.

The technical round remains 45 questions, now with a **40-minute** timer and a **34/45** qualification threshold.
